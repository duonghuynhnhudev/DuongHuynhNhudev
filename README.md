# DuongHuynhNhudev

> Portfolio of **Duong Dao Huynh Nhu (Heyzun)** — Mobile & Web Developer.

Built with **React 19**, **Vite**, **Tailwind CSS**, and modern UI/UX design.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack
- **Frontend & Core**: React 19, JavaScript (ES6+), Tailwind CSS
- **Design & UX**: Responsive Glassmorphism, Floating Micro-animations, Font Awesome
- **Bundler & Tooling**: Vite, Oxlint
