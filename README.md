## 📖 About This Project

This repository hosts the modern, interactive developer portfolio of **Duong Dao Huynh Nhu (Heyzun)**. Built from the ground up with **React 19**, **Vite**, and **Tailwind CSS**, the portfolio features:

- 🎨 **Modern Glassmorphism Design**: Multi-layered glowing ambient auras, squircle portrait framing, and responsive cards.
- ⚡ **Interactive Micro-Animations**: Floating floating badges, smooth 3D tilt effects, radar online status, and seamless section transitions.
- 📱 **100% Fully Responsive**: Pixel-perfect layout tailored for mobile devices, tablets, and ultra-wide screens.
- 🚀 **High Performance & SEO Optimized**: Near-instant load times powered by Vite, semantic HTML5, and Google Fonts (*Plus Jakarta Sans*).
